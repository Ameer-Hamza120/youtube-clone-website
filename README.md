# YouTube Clone Website

This project is a **YouTube website clone** that I developed as part of my web development learning journey. The main purpose of this project was to practice and improve my understanding of **HTML, CSS, JavaScript, responsive web design, and modern website layouts**.

The project recreates the general look and feel of a video-sharing platform, including a navigation bar, sidebar, video sections, thumbnails, categories, and other common elements found on a video streaming website.

## 📌 About the Project

This project was created while learning web development and experimenting with how real-world websites are structured and designed.

The goal was not to create an exact copy of YouTube, but rather to understand how to build a similar user interface from scratch and gain practical experience with frontend development.

Through this project, I practiced:

* Creating structured web pages using **HTML**
* Designing layouts using **CSS**
* Using **JavaScript** for interactive functionality
* Creating responsive layouts for different screen sizes
* Working with navigation bars and sidebars
* Creating video cards and thumbnail sections
* Organizing frontend project files
* Recreating a real-world website interface
* Improving UI design and user experience

## ✨ Features

Some of the main features included in this project are:

* YouTube-inspired homepage layout
* Navigation bar
* Sidebar navigation
* Video thumbnail cards
* Video titles and information
* Search interface
* Category/navigation sections
* Responsive webpage layout
* Clean and simple user interface
* Interactive frontend elements

## 🛠️ Technologies Used

The project was developed using:

* **HTML5** – Used to create the structure and content of the website
* **CSS3** – Used for styling, layouts, spacing, and responsive design
* **JavaScript** – Used to add interactive functionality and dynamic behavior
